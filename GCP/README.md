# GCP Hands on Lab

I started this journey notes on GitHub while taking the Associate Data Practitioner on GCP lab — mostly so I wouldn’t forget what I learned five minutes after finishing each exercise 😄

Along the way, I realized having everything written down (steps, mistakes, little “aha” moments) made it way easier to review later and actually understand what I was doing instead of just clicking through labs.

This repo is basically my personal cheat sheet + learning diary — a place to refresh my memory whenever I need to spin things up again or get stuck in the future.

Hope it helps future-me… and maybe you too 🚀
