### What is Seaborn?
Seaborn is a high-level visualization library for Python that helps you explore and understand data through charts. It provides built-in themes, color palettes, and functions for common statistical plots.

### When should you use Seaborn?

Use Seaborn when you want to:

Explore a dataset (EDA)

Visualize relationships between variables

Create quick, clean charts for analysis or reports

### Common plots you can make

- Trend over time → Line plot
- Compare categories → Bar chart
- Distribution of one variable → Histogram
- Relationship between two variables → Scatter plot
- Compare distributions → Box plot
- Correlation matrix → Heatmap
- Explore many variables → Pair plot

| Name             | Use When                                                                  | Example                                     |
| ---------------- | ------------------------------------------------------------------------- | ------------------------------------------- |
| **Line Plot**    | You want to show trends or changes over time or ordered data              | Sales revenue per month                     |
| **Bar Chart**    | You need to compare values across categories                              | Total sales by product category             |
| **Histogram**    | You want to understand the distribution of a single numeric variable      | Distribution of exam scores                 |
| **Scatter Plot** | You want to explore the relationship or correlation between two variables | Advertising spend vs revenue                |
| **Box Plot**     | You want to compare distributions and detect outliers across groups       | Salary distribution by department           |
| **Heatmap**      | You want to visualize a matrix or correlation between many variables      | Correlation matrix of dataset features      |
| **Pair Plot**    | You want a quick overview of relationships among multiple variables (EDA) | Exploring relationships in the Iris dataset |
